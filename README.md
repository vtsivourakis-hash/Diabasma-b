# Διάβασμα Β΄ Γυμνασίου

Στατική σελίδα μελέτης για την τάξη: Φυσική, Μαθηματικά, Αρχαία Ελληνική Γλώσσα, Ιλιάδα, συχνές ερωτήσεις για το σχολείο και χρονόμετρο μελέτης.
Live: https://vtsivourakis-hash.github.io/Diabasma-b/

## Δομή

```
index.html              ← ΠΑΡΑΓΕΤΑΙ από το build. Αυτό σερβίρει το GitHub Pages. Μην το διορθώνεις με το χέρι.
build.js                ← src/template.html + content/*.json → index.html (Node 18+, χωρίς εξαρτήσεις)
src/template.html       ← HTML, CSS, JS, ευρετήριο βιβλίων (BOOKS), FAQ σχολείου, ρυθμίσεις UPLOAD
content/                ← μία ενότητα ανά αρχείο JSON
  F-1.1.json            ← Φυσική 1.1     (κλειδί "F/1.1")
  M-A1.2.json           ← Μαθηματικά Α.1.2 (κλειδί "M/A1.2")
  A-r3.json             ← Ιλιάδα ραψωδία Γ (κλειδί "A/r3", καρτέλα «Ιλιάδα»)
  G-u2.json             ← Αρχαία Ελληνική Γλώσσα, ενότητα 2 (κλειδί "G/u2", καρτέλα «Αρχαία»)
  _grammar.json         ← πίνακες γραμματικής (κλίσεις ουσιαστικών, συζυγίες ρημάτων). Δεν είναι ενότητα.
notes-worker/           ← Cloudflare Worker για την αποστολή σημειώσεων (δες notes-worker/SETUP.md)
qr/                     ← script και PDF για τα καρτελάκια με το QR
sw.js                   ← service worker: η σελίδα ανοίγει και χωρίς internet
manifest.webmanifest    ← για «Προσθήκη στην αρχική οθόνη» (όνομα, χρώματα, εικονίδια)
icons/                  ← εικονίδια εφαρμογής (192, 512, 180 για iPhone)
```

## Καθημερινή δουλειά

```bash
node build.js                 # χτίζει το index.html
python3 -m http.server 8000   # προεπισκόπηση στο http://localhost:8000
git add -A && git commit -m "..." && git push   # σε 1–2 λεπτά είναι live
```

## Προσθήκη ενότητας

1. Βρες το id της ενότητας στο `BOOKS` μέσα στο `src/template.html` (π.χ. `"1.3"` στη Φυσική, `"A1.3"` στα Μαθηματικά, `"r6"` για τη ραψωδία Ζ, `"u3"` για την ενότητα 3 των Αρχαίων).
2. Φτιάξε το `content/<μάθημα>-<id>.json`, π.χ. `content/F-1.3.json`. Το ευρετήριο τη δείχνει αυτόματα ως «Έτοιμη».
3. `node build.js`. Το build σταματά με μήνυμα αν λείπει κάποιο υποχρεωτικό πεδίο.

Σχήμα (όλα τα κείμενα επιτρέπουν απλό HTML, π.χ. `<b>`, `<sub>`):

```json
{
  "title": "Τίτλος ενότητας",
  "exTitle": "Λυμένες ασκήσεις",
  "summary": [
    {
      "h": "Υπότιτλος",
      "t": "Απλή εξήγηση",
      "f": "τύπος (προαιρετικό)",
      "ex": "παράδειγμα (προαιρετικό)",
      "def": "ορισμός για το διαγώνισμα (προαιρετικό)",
      "defLabel": "αλλάζει την ετικέτα «Στο διαγώνισμα γράφεις» (προαιρετικό)",
      "quote": "στίχος πρωτοτύπου (προαιρετικό)",
      "warn": true
    }
  ],
  "quiz": [
    { "q": "ερώτηση", "c": "η σωστή απάντηση", "w": ["λάθος 1", "λάθος 2", "λάθος 3"], "why": "εξήγηση που φαίνεται μετά την απάντηση" }
  ],
  "ex": [
    {
      "q": "εκφώνηση",
      "lvl": 1,
      "learn": "Όπως μάθαμε, … (σύνδεση με τη θεωρία, προαιρετικό)",
      "topic": 2,
      "steps": ["βήμα 1", "βήμα 2"],
      "ans": "τελική απάντηση"
    }
  ]
}
```

`quiz`: οι «Ερωτήσεις επανάληψης». Η σελίδα ανακατεύει τις ερωτήσεις και τις απαντήσεις κάθε φορά. Οι λάθος απαντήσεις πρέπει να είναι σίγουρα λάθος, όχι «μισοσωστές».
`vocab` (προαιρετικό, για τα Αρχαία): λίστα από `["λέξη", "σημασία", "λέξεις των νέων ελληνικών"]`. Όταν υπάρχει, η ενότητα έχει και την καρτέλα «Λέξεις».
`lvl`: δυσκολία της λυμένης, υποχρεωτικό: 1 = Εύκολη, 2 = Μέτρια, 3 = Δύσκολη.
`{{τύπος|κλειδί}}`: σε οποιοδήποτε κείμενο, κάνει τη λέξη κουμπί που ανοίγει τον πίνακα γραμματικής `κλειδί` του `_grammar.json`, π.χ. `{{ἤγαγε|ago}}`. Το build σταματά αν το κλειδί δεν υπάρχει.
`_grammar.json`: κάθε ρήμα έχει `pp` (αρχικοί χρόνοι) και `tenses` (χρόνοι → εγκλίσεις → 6 πρόσωπα). Κάθε όνομα έχει `sg` και `pl` (5 πτώσεις). Το `book` είναι η σελίδα της σχολικής Γραμματικής (ebooks.edu.gr). Οι τύποι είναι δικοί μας πίνακες, όχι αντιγραφή κειμένου.
`topic`: ο αριθμός του θέματος της περίληψης που ανοίγει το κουμπί «Δες τη θεωρία». Μετράει από το 0, δηλαδή το πρώτο θέμα είναι το 0.

`warn: true` κάνει το μπλοκ «παγίδα» (κίτρινο με κόκκινη μπάρα).

## Εμφάνιση

Τα χρώματα είναι CSS variables στην αρχή του `src/template.html`. Υπάρχουν τρία μπλοκ: light, dark μέσω `prefers-color-scheme` και dark μέσω `data-theme`. Αν αλλάξεις χρώμα, άλλαξέ το και στα τρία.
Η σελίδα ανοίγει σε σκούρο θέμα (`<html data-theme="dark">`). Το κουμπί πάνω δεξιά αλλάζει σε φωτεινό, και η επιλογή μένει στο `localStorage` της συσκευής (`diab-theme`). Γραμματοσειρές: Inter για το κείμενο, Inter Tight για τους τίτλους, Literata για τύπους και στίχους. Τα εικονίδια είναι inline SVG, όχι emoji. Τα χρώματα είναι βιολετί (`--accent`) με διαβάθμιση βιολετί-ροζ για τα κουμπιά (`--grad`) και λάιμ για το «σωστό». Το `--hi` είναι το χρώμα για αριθμούς και ετικέτες.
Η πλοήγηση είναι μπάρα στο κάτω μέρος, όπως στις εφαρμογές. Η περίληψη και οι ερωτήσεις είναι κάρτες που αλλάζουν με σύρσιμο δεξιά-αριστερά, με τα κουμπιά ← → ή με τα βελάκια του πληκτρολογίου. Η καρτέλα «Εξάσκηση» έχει το Διαγώνισμα (ερωτήσεις από όσες ενότητες διαλέξεις, με ή χωρίς χρόνο), «Τα λάθη μου» και το Χρονόμετρο. Στο `localStorage` της συσκευής μένουν μόνο: `diab-mistakes` (ποιες ερωτήσεις απαντήθηκαν λάθος), `diab-best` (ο καλύτερος βαθμός ανά ενότητα), `diab-exam-sel` (οι ενότητες του τελευταίου διαγωνίσματος), `diab-rounds` (γύροι χρονομέτρου) και `diab-theme`. Δεν στέλνεται τίποτα πουθενά.
Το `sw.js` φέρνει πάντα πρώτα την τελευταία έκδοση από το δίκτυο, άρα οι νέες ενότητες φαίνονται αμέσως. Χωρίς δίκτυο δείχνει το αντίγραφο. Αν αλλάξουν τα εικονίδια, άλλαξε το `CACHE` στο `sw.js` (π.χ. `diabasma-v2`). Τα χρώματα δεν ακολουθούν πια το σχολείο. Ούτε λογότυπο ούτε όνομα του σχολείου (βλ. κανόνες πιο κάτω).

## Αποστολή σημειώσεων

Είναι απενεργοποιημένη όσο το `UPLOAD` στο `src/template.html` έχει κενά πεδία. Τα βήματα για το Cloudflare (Turnstile, R2, KV, secrets, deploy) είναι στο `notes-worker/SETUP.md`.
Ο φάκελος `notes-worker/` δεν χρειάζεται στο repo του Pages. Δεν περιέχει μυστικά, αλλά καλύτερα να ζει σε ξεχωριστό private repo.

## Κανόνες περιεχομένου

- Τα κείμενα γράφονται με δικά μας λόγια. Δεν αντιγράφουμε κείμενο από τα σχολικά βιβλία. Η σχολική μετάφραση της Ιλιάδας (Καζαντζάκη–Κακριδή) έχει πνευματικά δικαιώματα· αυτούσιοι στίχοι μόνο από το ομηρικό πρωτότυπο.
- Κάθε θέμα έχει απλή εξήγηση, παράδειγμα και τη σωστή διατύπωση για το διαγώνισμα.
- Ο Νίκος ελέγχει κάθε νέα ενότητα πριν ανέβει.
- Όχι όνομα ή σήμα του σχολείου στη σελίδα (άρθρο 18 του εσωτερικού κανονισμού) χωρίς γραπτή άδεια.

## Ανοιχτά θέματα

- [ ] Ο Νίκος να επιβεβαιώσει την ύλη των Μαθηματικών (ευρετήριο `BOOKS.M`). Η δομή δεν διασταυρώθηκε με το ίδιο το βιβλίο.
- [ ] Φυσική: η ύλη βασίζεται στη νέα έκδοση (Αντωνίου Ε. κ.ά., 6 κεφάλαια). Να επιβεβαιωθεί ότι αυτή χρησιμοποιεί η τάξη.
- [ ] Ο υπεύθυνος καθηγητής να δει την καρτέλα «Σχολείο». Κανόνας: δείχνουμε μόνο ό,τι λέει ο κανονισμός του σχολείου (Σεπτ. 2024) και δεν το αλλάζει η ΚΥΑ 102791/ΓΔ4/2024 (ΦΕΚ Β΄ 5130), που ισχύει και για τα ιδιωτικά σχολεία (άρθρο 30). Ό,τι δεν το λέει ο κανονισμός (π.χ. σύνθεση 5μελούς, απουσίες σε εγκεκριμένες δράσεις) δεν μπαίνει. Εξαίρεση: οι γραμμές βοήθειας για τον εκφοβισμό (stop-bullying.gov.gr, 1056). Αφαιρέθηκαν λόγω σύγκρουσης:
  - Όρια απουσιών: ο κανονισμός λέει «χωρίς διάκριση δικαιολογημένων/αδικαιολόγητων», η ΚΥΑ έχει 50 / 114 (άρθρο 25) και προσαύξηση για επαυξημένο πρόγραμμα.
  - Ενημέρωση γονέων: ο κανονισμός λέει 30 απουσίες, η ΚΥΑ 25 (άρθρο 26). Έμειναν οι «3 συνεχόμενες μέρες», που υπάρχουν και στα δύο.
  - Κινητό στην τάξη: ο κανονισμός λέει ωριαία και μετά ημερήσια αποβολή, η ΚΥΑ αποβολή 1 μέρας, έως 3 ή έως 5 (άρθρο 28 παρ. 4).
  - Κλίμακα μέτρων: ο κανονισμός έχει αποβολή 1 και 2 ημερών, η ΚΥΑ έως 3 και έως 5 και όχι αυστηρή σειρά (άρθρο 28 παρ. 2).
  - Πού είναι ο μαθητής στην αποβολή: ο κανονισμός λέει στο σχολείο, η ΚΥΑ στο σπίτι (άρθρο 28 παρ. 7).
  - Αν το σχολείο ενημερώσει τον κανονισμό του, τα θέματα αυτά μπορούν να ξαναμπούν.
- [ ] Αποστολή σημειώσεων: στήσιμο Worker (SETUP.md), ενημέρωση καθηγητή, lifecycle rule 30 ημερών.
- [ ] Ο Νίκος να ελέγξει τις «Ερωτήσεις επανάληψης» (σωστή απάντηση και 3 λάθος σε κάθε ερώτηση) και τα κουτιά «Θυμήσου τη θεωρία» στις λυμένες, στις 6 ενότητες που υπάρχουν.
- [ ] Ο Νίκος να ελέγξει τις ενότητες 1 και 2 των Αρχαίων (`G-u1`, `G-u2`): περίληψη, ερωτήσεις, λυμένες. Ειδικά τους αρχαίους τύπους (κλίσεις, χρόνους, τόνους).
- [ ] Ο Νίκος να ελέγξει τους 18 πίνακες γραμματικής στο `content/_grammar.json` (τόνοι, πνεύματα, καταλήξεις) και τη δυσκολία (`lvl`) των λυμένων.
- [ ] Ο Νίκος να ελέγξει τις 16 νέες Δύσκολες λυμένες (2 ανά ενότητα): τις λύσεις και τους αριθμούς.
- [ ] Ο Νίκος να ελέγξει το λεξιλόγιο (`vocab`) των ενοτήτων 1 και 2 των Αρχαίων.
- [ ] «5 λεπτά σήμερα» (καθημερινό μικρό κουίζ): θέλει πρώτα τρόπο να ξέρουμε τι έχει διδαχτεί στην τάξη, για να μη ρωτάμε για ενότητες που δεν έχουν γίνει.
- [ ] Επόμενες ενότητες: 2–3 την εβδομάδα, λίγο μπροστά από την τάξη.
