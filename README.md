# Διάβασμα · Α΄, Β΄, Γ΄ Γυμνασίου

Στατική σελίδα μελέτης για όλες τις τάξεις του δημόσιου ημερήσιου Γυμνασίου. Κατάλογος μαθημάτων 2026–2027, επίσημα βιβλία/PDF, αναζήτηση ενοτήτων και χρονόμετρο. Όλο το δικό μας περιεχόμενο (περιλήψεις, κουίζ, λυμένες) οργανώνεται με τη δομή των επίσημων βιβλίων: κάθε ενότητα έχει τη θέση της στο βιβλίο.
Live: https://vtsivourakis-hash.github.io/Diabasma-b/

## Κατάλογος για όλες τις τάξεις

- Μαθήματα και ώρες: ΥΑ 44257/Δ2/08-04-2026, ΦΕΚ Β΄ 2132, με ισχύ από το 2026–2027. Οι ώρες είναι 33 / 33 / 35. Η Ηθική είναι εναλλακτική των Θρησκευτικών και οι δεύτερες ξένες γλώσσες επιλογές, όχι πρόσθετες ώρες.
- Οι κωδικοί K07 / K08 / K09 είναι αναγνωριστικά του ebooks.edu.gr για Α΄ / Β΄ / Γ΄ Γυμνασίου, όχι διεθνείς κωδικοί εκπαίδευσης.
- Το `src/curriculum-config.json` ορίζει μαθήματα και αντιστοιχίσεις στο αποθετήριο. Το `src/curriculum.json` αποθηκεύει δημόσια μεταδεδομένα, επίσημους συνδέσμους και τίτλους ενοτήτων, όχι το περιεχόμενο των βιβλίων.
- Οι σύνδεσμοι περιεχομένων προέρχονται από το μενού των επίσημων HTML βιβλίων. Τα PDF δίνουν πρόσβαση στο πλήρες υλικό και για βιβλία χωρίς HTML έκδοση.
- Ηθική, Ιταλικά, Εργαστήρια Δεξιοτήτων και Τεχνολογία Γ΄ παραπέμπουν στις επίσημες οδηγίες/δραστηριότητες όπου δεν βρέθηκε βιβλίο μαθητή στον τρέχοντα κατάλογο.
- Η πλήρης έκταση ενός βιβλίου δεν ταυτίζεται με τη διδακτέα ή εξεταστέα ύλη. Η εφαρμογή παραπέμπει στις ετήσιες οδηγίες ΙΕΠ και στον/στην εκπαιδευτικό.
- Ο κατάλογος και οι ενσωματωμένες σημειώσεις λειτουργούν εκτός σύνδεσης μετά την πρώτη επίσκεψη. Τα εξωτερικά βιβλία χρειάζονται σύνδεση ή προηγούμενη λήψη PDF.

Ανανέωση μεταδεδομένων (Node 22.19+ για το προαιρετικό `--use-system-ca`):

```bash
node --use-system-ca scripts/import-curriculum.js
node build.js
```

Το build ελέγχει κάλυψη μαθημάτων, ώρες, αναγνωριστικά και επίσημους προορισμούς URL. Η εισαγωγή γίνεται κατά την ανάπτυξη· κανένα API δεν καλείται από τη συσκευή του μαθητή. Ενημέρωσε έτος και ημερομηνία στο config όταν διασταυρώνεις νέο πρόγραμμα.

Έλεγχοι browser (μόνο για ανάπτυξη):

```bash
npm install --no-save playwright
npx playwright install chromium
node scripts/test-browser.js
```

Ελέγχονται οι 67 διαδρομές μαθημάτων, αναζήτηση χωρίς τόνους, παλιές ενότητες, πρόοδος, κουίζ, διαχωρισμός τάξεων, ιστορικό, λειτουργία χωρίς σύνδεση και χωρίς localStorage. Προαιρετικά `PLAYWRIGHT_MODULE` / `CHROME_PATH` επιλέγουν ήδη εγκατεστημένα εργαλεία ελέγχου.

## Προσθήκη δικής μας ενότητας Β΄ Γυμνασίου

Συνήθως οι νέες ενότητες γράφονται στα `src/official-lessons-*.json`. Το `content/` είναι για ενότητες που χρειάζονται τύπους, κουμπιά γραμματικής ή λέξεις αρχαίων.

1. Βρες το κλειδί της ενότητας στο βιβλίο: τάξη/μάθημα/βιβλίο/ενότητα, με τη σειρά του `src/curriculum.json` (π.χ. `B/ancient/0/3`).
2. Φτιάξε το `content/B-ancient-0-3.json`. Αν η ίδια ενότητα καλύπτει κι άλλες του ίδιου βιβλίου, γράψε τες στο `"also"`. Η ενότητα ανοίγει από τη λίστα του βιβλίου (`#lesson/B/ancient/0/3`) με την ετικέτα «Πλήρες».
3. `node build.js`. Το build σταματά με μήνυμα αν λείπει κάποιο υποχρεωτικό πεδίο.

Σχήμα (όλα τα κείμενα επιτρέπουν απλό HTML, π.χ. `<b>`, `<sub>`):

```json
{
  "title": "Τίτλος ενότητας",
  "exTitle": "Λυμένες ασκήσεις",
  "summary": [
    {
      "h": "Υπότιτλος",
      "t": "Απλή εξήγηση",
      "f": "τύπος (προαιρετικό)",
      "ex": "παράδειγμα (προαιρετικό)",
      "def": "ορισμός για το διαγώνισμα (προαιρετικό)",
      "defLabel": "αλλάζει την ετικέτα «Στο διαγώνισμα γράφεις» (προαιρετικό)",
      "quote": "στίχος πρωτοτύπου (προαιρετικό)",
      "warn": true
    }
  ],
  "quiz": [
    { "q": "ερώτηση", "c": "η σωστή απάντηση", "w": ["λάθος 1", "λάθος 2", "λάθος 3"], "why": "εξήγηση που φαίνεται μετά την απάντηση" }
  ],
  "ex": [
    {
      "q": "εκφώνηση",
      "lvl": 1,
      "learn": "Όπως μάθαμε, … (σύνδεση με τη θεωρία, προαιρετικό)",
      "topic": 2,
      "steps": ["βήμα 1", "βήμα 2"],
      "ans": "τελική απάντηση"
    }
  ]
}
```

`quiz`: οι «Ερωτήσεις επανάληψης». Η σελίδα ανακατεύει τις ερωτήσεις και τις απαντήσεις κάθε φορά. Οι λάθος απαντήσεις πρέπει να είναι σίγουρα λάθος, όχι «μισοσωστές».
`vocab` (προαιρετικό, για τα Αρχαία): λίστα από `["λέξη", "σημασία", "λέξεις των νέων ελληνικών"]`. Όταν υπάρχει, η ενότητα έχει και την καρτέλα «Λέξεις».
`lvl`: δυσκολία της λυμένης, υποχρεωτικό: 1 = Εύκολη, 2 = Μέτρια, 3 = Δύσκολη.
`{{τύπος|κλειδί}}`: σε οποιοδήποτε κείμενο, κάνει τη λέξη κουμπί που ανοίγει τον πίνακα γραμματικής `κλειδί` του `_grammar.json`, π.χ. `{{ἤγαγε|ago}}`. Το build σταματά αν το κλειδί δεν υπάρχει.
`_grammar.json`: κάθε ρήμα έχει `pp` (αρχικοί χρόνοι) και `tenses` (χρόνοι → εγκλίσεις → 6 πρόσωπα). Κάθε όνομα έχει `sg` και `pl` (5 πτώσεις). Το `book` είναι η σελίδα της σχολικής Γραμματικής (ebooks.edu.gr). Οι τύποι είναι δικοί μας πίνακες, όχι αντιγραφή κειμένου.
`topic`: ο αριθμός του θέματος της περίληψης που ανοίγει το κουμπί «Δες τη θεωρία». Μετράει από το 0, δηλαδή το πρώτο θέμα είναι το 0.

`warn: true` κάνει το μπλοκ «παγίδα» (κίτρινο με κόκκινη μπάρα).

## Εμφάνιση

Τα χρώματα είναι CSS variables στην αρχή του `src/template.html`. Υπάρχουν τρία μπλοκ: light, dark μέσω `prefers-color-scheme` και dark μέσω `data-theme`. Αν αλλάξεις χρώμα, άλλαξέ το και στα τρία.
Κάθε μάθημα έχει χρώμα και εικονίδιο (`SUBJECT_LOOK` και `subjectIcon()` στο `src/catalogue.js`). Τα χρώματα είναι 8 μεταβλητές `--c-violet`, `--c-cyan`, `--c-lime`, `--c-green`, `--c-amber`, `--c-pink`, `--c-orange`, `--c-blue`, πιο σκούρες στο φωτεινό θέμα για να διαβάζονται. Οι εικόνες είναι μόνο δικά μας μικρά SVG μέσα στη σελίδα (όχι φωτογραφίες): το σχέδιο στην κάρτα της τάξης, το δαχτυλίδι του βαθμού (`gradeRing()`) και η εικόνα όταν δεν υπάρχουν λάθη. Σε SVG, τα χρώματα με `var(--…)` μπαίνουν σε `style`, όχι σε `fill=`/`stroke=`.
Η σελίδα ανοίγει σε σκούρο θέμα (`<html data-theme="dark">`). Το κουμπί πάνω δεξιά αλλάζει σε φωτεινό, και η επιλογή μένει στο `localStorage` της συσκευής (`diab-theme`). Γραμματοσειρές: Inter για το κείμενο, Inter Tight για τους τίτλους, Literata για τύπους και στίχους. Τα εικονίδια είναι inline SVG, όχι emoji. Τα χρώματα είναι βιολετί (`--accent`) με διαβάθμιση βιολετί-ροζ για τα κουμπιά (`--grad`) και λάιμ για το «σωστό». Το `--hi` είναι το χρώμα για αριθμούς και ετικέτες.
Η πλοήγηση είναι μπάρα στο κάτω μέρος, όπως στις εφαρμογές. Η περίληψη και οι ερωτήσεις είναι κάρτες που αλλάζουν με σύρσιμο δεξιά-αριστερά, με τα κουμπιά ← → ή με τα βελάκια του πληκτρολογίου. Η καρτέλα «Εξάσκηση» έχει το Διαγώνισμα, «Τα λάθη μου» και το Χρονόμετρο. Στο Διαγώνισμα ο μαθητής διαλέγει μάθημα της τάξης του και την ύλη (ολόκληρα κεφάλαια ή ενότητες, από όσες έχουν Quiz, παλιές και επίσημες). Μετά κάνει «Επανάληψη» (όλα τα θέματα της περίληψης, ένα ένα, σε κάρτες) ή «Δοκιμαστικό» (10, 20 ή όλες οι ερωτήσεις, με ή χωρίς χρόνο, και 0–3 λυμένες ασκήσεις για το τετράδιο, που δείχνουν τη λύση μόνο αφού το ζητήσει). Τα κεφάλαια βγαίνουν από τα περιεχόμενα του βιβλίου, ή από τον αριθμό της ενότητας (5.1 → Κεφάλαιο 5). Στο `localStorage` της συσκευής μένουν μόνο: `diab-mistakes` (ποιες ερωτήσεις απαντήθηκαν λάθος), `diab-best` (ο καλύτερος βαθμός ανά ενότητα), `diab-exam-sel` (οι ενότητες του τελευταίου διαγωνίσματος), `diab-exam-subj` (το μάθημα που διάλεξε), `diab-schedule` (το εβδομαδιαίο πρόγραμμα), `diab-rounds` (γύροι χρονομέτρου) και `diab-theme`. Δεν στέλνεται τίποτα πουθενά.
Το `sw.js` φέρνει πάντα πρώτα την τελευταία έκδοση από το δίκτυο, άρα οι νέες ενότητες φαίνονται αμέσως. Χωρίς δίκτυο δείχνει το αντίγραφο. Αν αλλάξουν τα εικονίδια, άλλαξε το `CACHE` στο `sw.js` (π.χ. `diabasma-v2`). Τα χρώματα δεν ακολουθούν πια το σχολείο. Ούτε λογότυπο ούτε όνομα του σχολείου (βλ. κανόνες πιο κάτω).

## Κανόνες περιεχομένου

- Τα κείμενα γράφονται με δικά μας λόγια. Δεν αντιγράφουμε κείμενο από τα σχολικά βιβλία. Η σχολική μετάφραση της Ιλιάδας (Καζαντζάκη–Κακριδή) έχει πνευματικά δικαιώματα· αυτούσιοι στίχοι μόνο από το ομηρικό πρωτότυπο.
- Κάθε θέμα έχει απλή εξήγηση, παράδειγμα και τη σωστή διατύπωση για το διαγώνισμα.

## Ασκήσεις του βιβλίου (καρτέλα «Βιβλίο»)

Για τις ασκήσεις και τις ερωτήσεις κατανόησης που προτείνει η ύλη ΙΕΠ, η ενότητα έχει καρτέλα «Βιβλίο». Δεν αντιγράφουμε την εκφώνηση: γράφουμε μόνο πού είναι (π.χ. «Ασκήσεις · 3»), με σύνδεσμο στην ενότητα του επίσημου βιβλίου (όχι σε σελίδα, γιατί οι σελίδες αλλάζουν ανά έκδοση) και σύνδεσμο στο δικό μας θέμα της θεωρίας, με κουμπί επιστροφής. Οι βοήθειες ανοίγουν μία μία· τουλάχιστον μία είναι επιλογή του μαθητή (σωστό ή λάθος με εξήγηση). Στο τέλος, μόνο αν το ζητήσει, βλέπει το ακριβές αποτέλεσμα για να ελέγξει τη δουλειά του. Δεν δίνουμε γραμμένη λύση για αντιγραφή.

Τα δεδομένα είναι στο `src/book-help-<μάθημα>.json`: κλειδί ενότητας (π.χ. `B/math/0/52`) → λίστα με `ref`, `lvl`, `topic` (θέμα της περίληψης, από 0), `hints` (βοήθειες `{h, t}` ή επιλογή `{q, c, w: [2 λάθος], why}`, τουλάχιστον 3) και `result`. Το build ελέγχει το σχήμα. Οι βοήθειες εμφανίζονται και στο Φύλλο ελέγχου ως «Βιβλίο».

## Εβδομαδιαίο πρόγραμμα (`#schedule`)

Στην «Εξάσκηση» → «Πρόγραμμα» ο μαθητής γράφει το πρόγραμμα της τάξης του (5 ημέρες × 7 ώρες). Κάθε ώρα είναι μάθημα της τάξης (σύνδεσμος στο μάθημα) ή ελεύθερο κείμενο («Άλλο…», π.χ. Φιλαναγνωσία). Μένει μόνο στη συσκευή (`diab-schedule`). Το «Στείλε το στην τάξη» φτιάχνει σύνδεσμο `#schedule/import/<κωδικός>`: ο κωδικός περιέχει το ίδιο το πρόγραμμα, οπότε δεν ανεβαίνει τίποτα στη σελίδα ή σε server. Όποιος ανοίγει τον σύνδεσμο βλέπει προεπισκόπηση και διαλέγει αν θα το αποθηκεύσει. Κανένα πρόγραμμα συγκεκριμένου τμήματος δεν μπαίνει στον κώδικα της σελίδας.

## Φύλλο ελέγχου (για τον Νίκο)

Ανοίγει στο https://vtsivourakis-hash.github.io/Diabasma-b/#review (δεν φαίνεται στο μενού). Δείχνει, ανά ενότητα, κάθε θέμα της περίληψης, κάθε λέξη, κάθε ερώτηση (με τη σωστή και τις 3 λάθος απαντήσεις), κάθε λυμένη (με τη δυσκολία της) και τους 18 πίνακες γραμματικής. Για κάθε στοιχείο πατάει ✓ Σωστό ή ✗ Θέλει διόρθωση, με σχόλιο. Οι σημειώσεις μένουν μόνο στη συσκευή του (`diab-review` στο `localStorage`). Το «Αντιγραφή αποτελεσμάτων» φτιάχνει κείμενο με τα ✗ και τα σχόλια, για να το στείλει.

Κάθε σημείωση δένεται με το ακριβές κείμενο του στοιχείου (hash). Όταν διορθώσουμε κάτι, η σημείωσή του χάνεται και το στοιχείο εμφανίζεται ξανά «Προς έλεγχο». Τα σωστά μένουν σωστά. Τα επίσημα μαθήματα του `src/official-lessons*.json` δεν είναι ακόμα στο φύλλο.

## Σχήματα στις κάρτες

Μια κάρτα της περίληψης στα `official-lessons-*.json` μπορεί να έχει πεδίο `"fig"`. Το σχήμα σχεδιάζεται από τη σελίδα ως SVG, με τα χρώματα του θέματος (light/dark), χωρίς εικόνες. Κάθε σχήμα θέλει `alt` (περιγραφή για αναγνώστες οθόνης) και μπορεί να έχει `caption`. Τύποι (λεπτομέρειες στο σχόλιο πάνω από το `figure()` στο `src/catalogue.js`): `line` (άξονας με σημεία και βέλη), `forces` (σώμα με δυνάμεις), `compose` (κάθετες δυνάμεις και συνισταμένη), `depth` (δοχείο με βάθη), `vessels` (συγκοινωνούντα δοχεία), `buoy` (δυναμόμετρο στον αέρα και στο νερό), `press` (υδραυλικό πιεστήριο), `scales` (κλίμακες θερμοκρασίας), `energy` (στήλες U και K), `chain` (αλυσίδα μετατροπών ενέργειας), `split` (απόδοση). Το build ελέγχει τα δεδομένα κάθε σχήματος. Τα σχήματα φαίνονται και στο Φύλλο ελέγχου.

## Δοκιμαστική τοπική εφαρμογή

Το κουμπί «Λήψη app» προσφέρει το `downloads/Diabasma-test-windows.zip`, που παράγεται με `node build.js`. Αποσυμπίεσε και άνοιξε το `Start-Diabasma.cmd`: χρησιμοποιεί εγκατεστημένο Edge ή Chrome σε δικό του παράθυρο. Το αυτόνομο HTML περιλαμβάνει τον κατάλογο και τις ενσωματωμένες ενότητες χωρίς server ή σύνδεση. Τα εξωτερικά βιβλία χρειάζονται internet. Είναι στιγμιότυπο δοκιμής, χωρίς αυτόματες ενημερώσεις ή μεταφορά προόδου από το site. Σε υποστηριζόμενες συσκευές προσφέρεται και εγκατάσταση της PWA. Η πλοήγηση έχει Αρχική, Πίσω, Αναζήτηση, Χρονόμετρο και συνέχεια της τελευταίας ενότητας· σε μεγάλες οθόνες εμφανίζεται πλαϊνή μπάρα.

Κάθε καταχωρισμένη ενότητα των επίσημων βιβλίων ανοίγει με την ίδια ροή μελέτης: κάρτες, λέξεις, έξι ερωτήσεις Quiz και πέντε δραστηριότητες. Όπου υπάρχει συγγραφικά ελεγμένο υλικό, αυτό αντικαθιστά τον γενικό οδηγό μελέτης. Ο γενικός οδηγός χρησιμοποιεί τον τίτλο και τη θέση της ενότητας στο βιβλίο και παραπέμπει στο επίσημο βιβλίο για τις ακριβείς πληροφορίες.

Το `src/explanations.json` περιέχει σύντομες, πρωτότυπες εξηγήσεις που έχουν ελεγχθεί με το επίσημο βιβλίο και την ύλη/τις οδηγίες ΙΕΠ 2026–2027. Το `status` είναι `core` (βασικό), `modified` (βασικό με την προσαρμογή που περιγράφεται στο `syllabusNote`) ή `optional` (πρόσθετο/προαιρετικό). Κάθε ενότητα βιβλίου έχει μία από τρεις ετικέτες, ανάλογα με το τι θα βρει ο μαθητής (`lessonLevel` στο `src/catalogue.js`):
- **Πλήρες**: περίληψη, λέξεις, ερωτήσεις και λυμένες γραμμένες για αυτή την ενότητα. Είναι οι ενότητες των `official-lessons*.json` και του `content/` (π.χ. η Α1.1 των Μαθηματικών Β΄ είναι το `content/B-math-0-2.json`).
- **Εξήγηση**: μόνο σύντομη εξήγηση από το `explanations.json`· οι ερωτήσεις και οι δραστηριότητες είναι ακόμα γενικές.
- **Οδηγός**: γενικές οδηγίες μελέτης· το περιεχόμενο είναι στο επίσημο βιβλίο.
Οι προαιρετικές ενότητες της ύλης 2026–2027 έχουν και τη σημείωση «Προαιρετικό στην ύλη».
